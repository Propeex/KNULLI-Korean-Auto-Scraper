# KNULLI Korean Auto Scraper v0.8.6 Beta 1

**Windows / RG35XX Plus / KNULLI / USB ADB**

> **Beta / Pre-release**입니다. GitHub 자동 테스트는 통과했지만 실제 Windows에서 파일 교체와 자동 재시작 전체 과정을 아직 확인하지 못했습니다.

## 주요 새 기능 — 실행 시 자동 업데이트

- 프로그램을 `GUI_실행.pyw` 또는 `GUI_실행.vbs`로 실행하면 GitHub의 **공개 베타 릴리즈** 중 최신 버전을 확인합니다.
- 새 베타가 있으면 사용자의 승인을 묻지 않고 Windows ZIP을 다운로드합니다.
- SHA-256 검사 파일과 GitHub Release digest, ZIP 내부 경로·파일 목록·버전을 검사합니다.
- 검증을 통과한 경우 실행 중인 앱을 종료하고 별도 업데이트 도우미가 **프로그램 파일만 교체**한 후 새 버전으로 자동 재시작합니다.
- 인터넷 연결이 없거나 GitHub 오류/검증 실패가 발생하면 기존 앱을 실행합니다. 프로그램 교체 중 실패하면 이전 코드 복구를 시도합니다.
- 여러 인스턴스가 동시에 업데이트하지 않도록 잠금을 사용합니다.

## 최초 설치 안내 — 중요

**이전 `v0.8.5-beta.2`에는 업데이트 기능이 없습니다.** 따라서 이번 `v0.8.6-beta.1`은 아래 Windows ZIP을 **처음 한 번 직접 다운로드해 설치**해야 합니다. 이번 버전이 설치된 뒤에는 이후 공개 베타가 나올 때부터 자동 업데이트됩니다.

새 폴더에 압축 해제 후 `GUI_실행.pyw`를 실행하세요. 설치에 Python **3.10 이상**과 Tkinter가 필요합니다. **독립 실행 EXE가 아닌 Python GUI 패키지**입니다.

기존 계정·설정과 영문명 사전은 사용자 문서 폴더에 있어 별도로 다시 입력할 필요가 없습니다. 사용자 수정 `aliases.json`/ `artwork.xml`도 자동 업데이트 과정에서는 덮어쓰지 않도록 보호합니다.

## 안전성

- 갱신 대상은 프로그램 코드와 릴리즈의 안내 파일입니다.
- ROM, 게임기 `gamelist.xml`, 이미지·영상, PC의 스크래핑 캐시, 사용자 설정과 자격 증명은 업데이트하지 않습니다.
- 업데이트를 위한 **임시 프로그램 코드 롤백**은 있을 수 있지만, 이전 요청대로 **스크랩 데이터 XML 백업은 만들지 않습니다**.
- 실패 로그: `Documents\KNULLI Auto Scraper Data\auto_update.log`.
- 정식판(Stable)은 사용자가 승인하기 전까지 자동 설치하지 않습니다.

## 기존 기능

- Windows PC에서 게임 정보 및 관련 미디어를 검색해 USB ADB로 KNULLI에 적용
- 한글 이름 및 하위 폴더 경로 처리
- 삭제된 ROM의 XML 정보와 전용 자원 확인 후 사용자 승인 시 정리
- 사용자 요청에 따른 자동 스크랩 XML 백업 미생성

## 테스트

- GitHub Actions에서 Python/GUI 회귀 테스트 수행, ZIP 빌드 및 체크섬 검증 후 발행.
- 자동 업데이트 기능: 최신 베타 선택, 다운그레이드 방지, 변조된 ZIP 거부, 사용자 데이터 보호, 업데이트 코드 롤백, 자동 재시작 호출, 동시 설치 잠금.
- **실제 Windows + RG35XX Plus 환경에서의 전체 업데이트 동작은 사용자 실기기에서 추가 검증이 필요합니다.**
