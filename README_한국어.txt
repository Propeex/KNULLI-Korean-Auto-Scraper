KNULLI Auto Scraper v0.8.7-beta.3 (Windows / RG35XX Plus / USB ADB)
=====================================================

시작하기
---------
1. RG35XX Plus를 기존 USB ADB 연결 방식으로 PC에 연결합니다.
   PC에 인터넷만 연결되어 있으면 됩니다. 기기 자체 인터넷 연결은 필요하지 않습니다.
2. ZIP을 새 폴더에 압축 해제합니다.
3. GUI_실행.pyw 를 더블클릭합니다. Python 3.10+와 Tkinter가 필요합니다.
   파일 연결 문제가 있을 때만 GUI_실행.vbs를 실행하세요.
4. 프로그램이 ADB와 Skyscraper 엔진을 찾아서 재사용합니다.
   없으면 공식 배포 파일을 PC에서 자동 다운로드합니다.
   첫 설치에 PC 인터넷 연결이 필요할 수 있습니다.
5. 자동으로 나타난 ROM 목록에서 대상 게임을 선택하고 '작업 시작'을 누릅니다.

v0.8.3 화면 개선
-----------------
- 청색이 없는 검정/회색 다크 모드를 적용했습니다. (작업 실패 안내 등 경고색 제외)
- ROM 목록은 체크박스 / 기종 / 게임명 / 상태의 4개 열로 표시합니다.
- 상태 열은 작업 성공, 데이터 있음, 검색 실패, 데이터 없음 등으로 구분합니다.
  이미지가 없더라도 설명이나 평점 등이 있으면 '데이터 있음'으로 표시됩니다.
- 교차 줄무늬 배경을 없애고, 현재 열어 본 행에만 눈에 띄는 회색 음영을 표시합니다.
- 영어 게임명 입력칸을 줄이고 별도의 저장 버튼을 제거했습니다.
  입력을 약 0.85초 멈추거나 Enter를 누르거나 다른 게임으로 이동하면
  영어 게임명이 사용자 데이터 폴더의 manual_titles.json에 자동 저장됩니다.
- 이미 작업 중인 항목의 상태를 표시하며, 완료된 게임은 즉시 상태가 갱신됩니다.
- 기존 게임 정보/설정의 스크롤 기능은 유지합니다.
- ADB 연결과 스크래핑, ROM 이름 변경은 유지합니다. v0.8.5-beta.2부터 XML 백업은 자동 생성하지 않습니다.

ROM 목록 조작
--------------
- 열 구조: 체크박스 / 기종 / 게임명 / 상태
- 한 번 클릭: 오른쪽에 게임 정보 표시
- 체크박스 클릭, 행 더블클릭, Space: 체크/해제
- 방향키 위/아래: ROM 이동
- 전체 선택: 모든 게임 체크
- 데이터 없는 게임 선택: 게임 표시명 이외의 설명/평점/장르/실제 자원 등이
  하나도 없는 게임만 체크. 이미지가 없지만 설명이 있다면 체크하지 않습니다.
- 실패 항목 선택: 직전 작업 기록의 검색 실패/오류 게임만 체크
- 작업 시작: 체크한 게임만 재스크래핑. 기존 자료가 있어도 선택 가능
- 새로고침, 선택 해제, 도구 자동 복구 버튼은 제거했습니다.

게임 정보 화면
---------------
- 이름: 일반 단일 ROM은 실제 파일명을 바꾸며 확장자는 고정됩니다.
  이름 변경 시 gamelist.xml 경로와 연결 자원 파일 이름도 가능한 범위에서 수정합니다.
- Neo Geo·MAME 등 이름이 중요한 묶음 ROM: 실제 파일명은 유지하고
  KNULLI의 게임 표시명(<name>)만 편집합니다. (예: mslug.zip → 메탈슬러그)
- 영어 게임명: 입력만 하면 자동 저장됩니다. 프로그램을 교체해도 설정이 유지됩니다.
- 이미지: 현재 gamelist.xml의 <image> 자원을 고정 미리보기로 보여줍니다.
- 게임 정보: 장르·평점·출시일·개발사·배급사·지원 인원을 읽기 전용으로 표시합니다.
- 설명: 직접 수정하고 '설명 저장'을 눌러 기기의 gamelist.xml에 적용합니다.
- 자동/수동 번역 기능은 제거했습니다.
- 전체 작업이 진행 중이어도 게임별 스크래핑이 끝나면 상세 정보가
  바로 갱신됩니다. 작업 중에는 보기만 가능하고 편집은 잠금 처리됩니다.
- 기존 XML은 변경 여부를 확인한 뒤 수정하며 백업 사본은 만들지 않습니다. 기기 ROM의 원본 내용은 스크래핑 중 변경하지 않습니다.

저장 위치 — 앱 폴더와 독립적
---------------------------
사용자 문서 폴더\KNULLI Auto Scraper Data\
  settings.json       스크래핑 설정 (비밀번호 없음)
  title_map.csv       성공한 한글명/영어명 대응표 (엑셀, 메모장 등에서 확인 가능)
  learned_titles.json 같은 대응표의 내부 보존용 JSON
  manual_titles.json  사용자가 입력한 영어 검색어

ScreenScraper 일반 계정 ID와 비밀번호는 Windows 자격 증명 관리자에서
'KNULLI Auto Scraper / ScreenScraper' 항목으로 저장합니다.
앱을 새 버전으로 교체해도 남습니다. 이전 버전의 config.json에서 자동
가져오기를 시도하지만, 오래된 버전의 config.json에 남은 평문 비밀번호는
사용자가 직접 정리하는 것이 좋습니다.

Skyscraper 엔진에 계정을 전달하려고 필요한 임시 INI는 작업 중 만들고
정상 종료 시 삭제합니다. Windows가 강제 종료되면 임시 파일이 남을 수 있습니다.

성능/안정성
------------
- 게임 목록을 한 번 조회하고, 자원 존재 여부는 ADB 명령을 묶어서 확인합니다.
- 성공한 게임은 전체 재스캔 없이 해당 게임의 XML·자원만 다시 확인합니다.
- 기존 이미지 미리보기는 로컬 캐시를 재사용합니다.
- 제목 매칭에 성공하면 기종별 한글↔영문명 사전을 자동 갱신합니다.
- USB ADB 서버를 강제로 종료/재시작하지 않습니다.
- 현재 구형 Skyscraper Windows 엔진은 처리할 ROM을 PC 임시 폴더로
  복사해 조회하므로 대형 ROM에는 시간이 걸립니다. ScreenScraper 서버
  속도와 요청 제한은 프로그램이 무리해서 우회하지 않습니다.

알려진 제한
------------
- 타이틀 화면(sstitle)은 KNULLI가 지원하지만 현재 Windows용
  Skyscraper 3.6.12의 수집 연결이 검증되지 않아 선택할 수 없습니다.
  Pad2Key 다운로드도 아직 제공하지 않습니다.
- KNULLI 스크래퍼 설정 범주를 참고하지만 사용 중인 구형 Skyscraper가
  지원하지 않는 옵션은 비활성화되어 있습니다.
- 미리보기 PNG/GIF는 기본 표시되며, JPG/WEBP는 Python Pillow가
  설치된 경우 표시됩니다.
- ROM 이름 변경이 저장 파일·외부 설정의 이름까지 자동으로 변경하지는
  않으므로 중요한 게임의 파일명 수정은 백업 후 시도하세요.
- 실제 사용자 Windows/실기기/ScreenScraper 서버 종단간 테스트는 이
  환경에서 수행하지 못했습니다. 자동 테스트와 가상 GUI 테스트만 완료했습니다.
- ZIP에 타사 실행 파일을 포함하지 않습니다. 인터넷이 연결된 PC에서
  처음 시작할 때 필요한 파일을 공식 소스에서 내려받습니다.

[v0.8.3 수정]
- 선택된 게임 행은 밝은 회색 음영, 굵은 글씨, 체크 칸의 ▸ 표시로 강조합니다.
- 한글 파일명을 가진 단일 파일 ROM의 기존 gamelist.xml <name>이
  영문인 경우, ROM 목록을 여는 과정에서 해당 기기의 이름을 한글로 동기화합니다.
  기존에 직접 지정한 한글 표시명은 보존합니다.
- 실제 ROM, 게임 설명, 이미지, 영상 등은 변경하지 않습니다.
- v0.8.5-beta.2부터는 XML 백업을 만들지 않고 변경 여부 검사 후 갱신합니다.
- Neo Geo ZIP 등 이름 변경 제한 ROM은 자동 변환하지 않으며
  프로그램의 게임명 저장 기능으로 한글 표시명을 정할 수 있습니다.
- KNULLI 실행 중 이미 로드된 게임 목록은 변경 내용이 즉시 보이지 않을 수
  있습니다. KNULLI에서 게임 목록 갱신 또는 안전한 재시작을 해주세요.


[v0.8.4 수정: 한글 하위 폴더 경로 오류]
----------------------------------------
- 예: /userdata/roms/psx/한글 게임 폴더/Silent Hill (K).cue
- v0.8.3에서 ADB 셸 탐색 출력의 한글 경로 부분이 '?'로 깨져
  `remote file size unavailable` 오류가 발생할 수 있었습니다.
- v0.8.4는 기기 셸에서 경로를 NUL 구분 바이트로 수집하고,
  영문·숫자만 있는 16진수로 변환해서 PC에 가져온 뒤 UTF-8로 복원합니다.
- 파일 크기 조회도 ADB에 한글 경로를 직접 전달하지 않고 안전한
  8진수 인코딩으로 원래 경로를 구성하여 조회합니다.
- PS1의 .cue/.bin 등 게임 파일 내용은 변경하지 않습니다.
  복사/검색 단계에서 별도의 메시지가 나올 경우 work/last_report.json을 확인하세요.
- 한글 하위 폴더 이름을 영문으로 바꿀 필요는 없습니다.
- KNULLI 기기와 ScreenScraper 서버의 전체 실사용 검증은 별도입니다.


[v0.8.5 추가: ROM 삭제 후 관련 자료 정리]
------------------------------------------
- 사용자가 기기에서 ROM 파일을 삭제하면 다음 ROM 조회 때 gamelist.xml에서 남은 게임 정보를 찾습니다.
- ROM이 실제로 없는지 ADB에서 다시 확인합니다.
- 다른 게임과 공유하지 않는 이미지·동영상·매뉴얼 중 안전한 경로만 정리 대상으로 잡습니다.
- 정리할 게임·파일 수를 보여주고 사용자가 승인한 경우에만 삭제합니다.
- gamelist.xml과 삭제된 미디어 모두 자동 백업하지 않습니다. 정리 전에 대상 확인이 필요합니다.
- 정리 결과는 work/last_cleanup.json에 기록됩니다.
- 실기기에서 검증 전이므로 처음에는 중요하지 않은 시험 데이터로 확인해 주세요.

[v0.8.5-beta.2 수정: 셸 명령 길이 오류 / 스크랩 데이터 백업 제거]
----------------------------------------------------------------
- 한글 파일·폴더명 다수 검사 시 ADB 명령이 너무 길어지는 문제를 분할 검사로 수정했습니다.
- ADB 응답이 불완전하면 게임이 삭제됐다고 추정하지 않고 정리를 중단합니다.
- 스크래핑, 한글명 동기화, 설명/표시명 수정, ROM 이름 변경, 삭제 게임 정리 중 XML 백업을 생성하지 않습니다.
- 기기의 gamelist.xml.knulli-autoscraper-<시간>.bak를 시스템별로 검사해 삭제합니다.
- PC에서는 현재 프로그램과 같은 상위 폴더에 있는, 식별 가능한 이전 설치본의 work/xml_backups 자료만 삭제합니다.
- 기존 gamelist.xml 본파일, ROM, 이미지·영상, 사용자 수동 백업, 계정/설정은 삭제하지 않습니다.
- 이전 설치본이 다른 위치에 있으면 안전을 위해 자동 검색·삭제하지 않습니다.
- 자동 백업이 없으므로 예상치 못한 오류에서 복구가 어려울 수 있습니다.


[v0.8.6-beta.1 추가: 실행 시 베타 자동 업데이트]
-------------------------------------------------
- Windows에서 GUI_실행.pyw 또는 GUI_실행.vbs를 실행하면 최신 GitHub 베타 릴리즈를 자동 확인합니다.
- 새 베타가 있으면 별도 승인 없이 PC로 Windows ZIP을 다운로드해 SHA-256을 검증합니다.
- 실행 중인 프로그램을 종료하고 업데이트 도우미가 프로그램 파일만 교체한 뒤 자동 재시작합니다.
- 데이터 파일, ROM, 기기 gamelist.xml, 사용자 설정, 스크랩 캐시, 기존 수정된 aliases.json·artwork.xml은 보존합니다.
- 설치가 실패할 경우 가능한 범위에서 기존 프로그램 파일로 복구하고 다시 실행합니다.
- PC 인터넷이 없거나 GitHub에 접속할 수 없을 때는 현재 버전으로 계속 실행합니다.
- 사용자가 정식판을 승인하기 전에는 베타(Pre-release)만 자동 설치합니다.
- 이전 v0.8.5-beta.2에는 자동 업데이트 기능이 없으므로 이번 v0.8.6-beta.1은 처음 한 번 수동 설치해야 합니다.
- 향후 릴리즈부터는 실행할 때 자동 업데이트됩니다.
- 오류 기록: Documents\KNULLI Auto Scraper Data\auto_update.log
- Windows 실기기에서 업데이트 전체 과정은 아직 검증 전입니다.


[v0.8.7-beta.1: PortMaster 포팅 게임 지원]
----------------------------------------------
- KNULLI roms/ports 최상위 .sh 실행 파일을 PortMaster 게임으로 목록에 표시합니다.
- PortMaster.sh 및 Install.PortMaster.sh 등 관리/설치용 스크립트는 게임으로 취급하지 않습니다.
- 목록에서 원하는 포트 게임을 선택하고 작업 시작을 누르면 port.json과 gameinfo.xml을 읽습니다.
- 설치된 cover.png/.jpg 또는 screenshot.png/.jpg를 기존 경로 그대로 XML에 연결합니다.
- gameinfo.xml을 우선 적용하고 부족한 항목은 port.json으로 보완합니다.
- 사용자가 입력한 게임명/설명/이미지를 보존하며 비어 있는 게임 정보만 보완합니다.
- 실행 스크립트 .sh, 게임 데이터/세이브 폴더, 원본 미디어는 수정하거나 삭제하지 않습니다.
- 포트 게임 작업만 선택했다면 Skyscraper/ScreenScraper 설치와 접속이 필요 없습니다.
- 포트 데이터가 없거나 런처 정보가 일치하지 않으면 다른 게임으로 추정하지 않고 정보 없음으로 표시합니다.
- 사용자의 요청대로 프로그램은 XML 스크랩 백업을 자동 생성하지 않습니다.
- 실제 사용자 RG35XX Plus의 다양한 PortMaster 게임 설치 방식은 아직 실기기 검증 전입니다.

[v0.8.7-beta.3: PSP rom_too_large 오류 수정]
---------------------------------------------
- 이전에는 스크래핑 전에 PSP ISO 등 모든 ROM을 USB ADB로 PC에 복사했습니다.
- 기본 256MB 전송 제한을 넘으면 rom_too_large로 스크래핑도 시도하지 못했습니다.
- 이제 큰 .iso, .cso, .pbp, .chd, .cdi, .gdi 디스크 ROM은 전체 데이터를 PC에 받지 않습니다.
- 대신 영문 검색명을 사용해 ScreenScraper/Skyscraper로 게임 정보와 이미지를 찾습니다.
- 게임명 일치도가 낮으면 잘못된 게임 정보를 적용하지 않습니다.
- 작은 ROM은 기존 해시 기반 검색을 유지하고, 큰 .zip/.7z 파일은 용량 제한을 유지합니다.
- ROM 원본과 사용자 한글 게임명은 변경하지 않습니다. XML 자동 백업도 생성하지 않습니다.
- 실제 사용자 PC의 Skyscraper 및 기기에서 검색 결과는 아직 실기기 확인 전입니다.
