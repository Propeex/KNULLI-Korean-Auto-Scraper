# 핵심 결정 및 절대 규칙

## 사용자와 합의한 제품 원칙
1. ROM 파일의 **한글 파일명**과 KNULLI의 **한글 표시명**을 기본적으로 보존한다.
2. 영문 게임명은 ScreenScraper **검색용**이며 기기에 영어 표시명으로 자동 덮어쓰지 않는다.
3. 게임기 종류를 사용자에게 강제로 요구하지 않는다. KNULLI 시스템 폴더를 우선하고 확장자/파일 정보는 보조로 사용한다.
4. 사용자는 ROM 준비, 프로그램에서 게임 선택과 필요한 최소한의 영문 검색어 수정만 한다. 복사/이미지 이동/gamelist.xml 병합은 앱 담당.
5. 기존 자료 재스크래핑 가능. 데이터 없음 선택은 이미지/설명/장르 등 **의미 있는 스크래핑 데이터가 하나도 없는 게임**만 선택.
6. 안전을 위해 실패 시 게임에 잘못된 데이터를 무조건 적용하지 않는다.
7. 사용자 요청(2026-11-23)으로 프로그램 자동 gamelist.xml 스크래핑 백업을 생성하지 않음. 이전 프로그램이 만든 백업만 기기 및 확인 가능한 설치 폴더에서 정리. ROM 원본 내용 비수정, KNULLI OS 무수정, ADB 서버 kill/restart 금지.
8. 보호 대상(Neo Geo/MAME/FBNeo 등) ROM 세트는 실제 ZIP 이름을 유지하고 사용자 지정 표시명(`<name>`)만 허용한다.
9. 계정 비밀번호는 소스·로그·GitHub에 저장하지 않는다. 일반 ScreenScraper 계정만 있으면 되도록 구형 Skyscraper 엔진을 사용한다.

## UI 설계 결정
- 검정/회색 다크 모드. 파란 테마/교차 행 음영 불필요.
- 게임 목록 열: **선택(체크박스) / 기종 / 게임명 / 상태**.
- 단일 클릭: 게임 상세 조회; 더블 클릭, Space: 체크/해제; ↑↓ 이동.
- 현재 조회 중인 행은 명확한 음영 + 마커로 강조하며, 체크된 여러 행과 혼동되지 않게 한다.
- 상단 버튼: 전체 선택, 데이터 없는 게임 선택, 실패 항목 선택, 작업 시작.
- 제거: 새로고침, 선택 해제, 도구 자동 복구, 불필요한 예시 문구·경로 상태 텍스트.
- 게임 정보: 하나의 화면. 이름(확장자 제외)/영문 검색명/고정 대표 이미지/메타데이터/설명. 메타데이터는 설명만 편집 가능.
- 영어명 입력은 지연 자동 저장(약 850ms, Enter, 선택 변경). 별도 저장 버튼 없음.
- 작업 중 완료된 게임은 즉시 조회 가능, 편집은 작업 종료까지 잠금.
- 설명 자동 번역 기능 제거.
- 데이터는 앱 폴더 밖 사용자 문서 폴더/Windows 자격 증명 관리자에 저장.

## PortMaster 지원 원칙 (2026-11-23)

- KNULLI Ports는 **루트 `.sh` 런처만 게임으로 간주**. PortMaster 설치/관리 도구는 제외하고 포트 게임 데이터 폴더 전체를 ROM으로 탐색하지 않음.
- `gameinfo.xml`을 우선으로 읽고, 유효한 `port.json`의 명시적 `items`와 대조. 불일치/다중 매칭은 추측하지 않고 건너뜀.
- 기존 `gamelist.xml`의 사용자 변경 내용은 보존, 빈 메타데이터와 누락 미디어 경로만 작성. 실행 스크립트·게임 데이터·세이브·보유 미디어 파일은 수정하지 않음.
- PortMaster-only 작업은 Skyscraper/ScreenScraper 설치 요구가 없으며 기기 인터넷 불필요.
- 사용자 요청대로 새 XML 백업을 만들지 않고, 기존 앱 생성 백업 제거 정책 유지.

## 운영·기술 결정
- PC 인터넷은 필요, **기기 자체 인터넷은 불필요**.
- USB ADB로 기기 파일에 직접 접근. `adb kill-server` 금지.
- Skyscraper 기반 Windows 스크래퍼 사용; 구형 엔진 지원 범위를 솔직히 표시.
- 한국어 하위 폴더는 이름을 영문으로 변경시키기보다 인코딩을 올바르게 처리한다.
- 타이틀 화면은 KNULLI가 지원하나 구형 Windows 엔진에서 수집 경로 미검증 — 차기 검토.
- 키보드/패드 Pad2Key는 우선순위 제외(PortMaster 관련 사용).
