# 변경 이력

## v0.8.4 — GitHub 최초 이식 기준(2026-11-20)
- 한글 하위 폴더 경로의 ADB 탐색/파일 크기 조회 인코딩 보완.
- 문제 사례: `psx/한글 게임 폴더/Silent Hill (K).cue` → 경로 `????`, 파일 크기 확인 불가.
- 가상 환경 테스트 60개 통과; 실기기 결과는 미확인.
- **이 GitHub 이식은 v0.8.4 기준 코드 보존 작업이며 기능 수정/업그레이드가 아님.**
