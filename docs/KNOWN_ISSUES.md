# 알려진 문제 및 검증 상태

## 아직 검증되지 않은 사항
- **v0.8.5 ROM 삭제 후 자료 정리:** 실기기 테스트 전. `gamelist.xml`에 명시적으로 연결된 안전한 미디어 경로만 삭제 후보로 취급; 파일명만 유사한 미연결 자원은 삭제하지 않음. 다른 게임과 공유한 경로는 보호. 조회 시 사용자가 정리 승인해야 실제 삭제됨. **v0.8.5-beta.2부터 XML 백업도 생성하지 않음.** 미디어 정리 전 사용자 확인 필수.
- **모든 게임이 삭제된 ROM 시스템:** v0.8.5에서 빈 목록 처리 코드를 보완했으나, 실제 기기에서 해당 시나리오의 동작은 아직 검증 전.
- **v0.8.4의 한글 하위 폴더 수정이 실기기에서 성공했는지:** 사용자 재실행 결과 미수신.
- **타이틀 화면(ssTitle):** KNULLI는 지원하지만 Windows Skyscraper 3.6.12에서 별도 타이틀샷 다운로드/적용 경로 미검증.
- **대형 ROM 속도:** 구형 Skyscraper는 임시 복사가 필요할 수 있어 느릴 수 있음.
- **전 게임기/파일 형식 호환:** 특히 `.cue`/`.bin`, `.m3u`, 다중 디스크, 아케이드 세트는 더 검증해야 함.
- **실제 Windows 자동 설치:** ADB와 Skyscraper 설치 경로·DLL·압축 해제는 기기별로 환경 차이가 있음.
- **GUI 미디어 미리보기:** JPG/WEBP에 Pillow가 필요할 수 있음.

## 이번에 수정한 문제
- v0.8.5-beta.1 실기기: `삭제된 게임 검사 실패: ADB shell failed: error: shell command too long`. 한글 경로 인코딩이 긴데 12개씩 묶고 한 경로를 두 번 인코딩해 ADB 셸 명령 크기 초과. v0.8.5-beta.2에서 명령 크기 제한·재분할·실패 시 중단하도록 수정. CI 테스트 통과, **실기기 재시험은 아직**.

## 자동 업데이트 확인이 필요한 사항 (v0.8.6-beta.1)
- GitHub Actions Linux 테스트에서는 정상. **Windows 실제 프로세스 종료 후 교체·재시작은 아직 실사용 검증 전**.
- 앱 설치 폴더 쓰기 권한이 없다면 자동 업데이트가 실패할 수 있음. 실패 시 가능한 범위에서 기존 앱을 재실행하고 사용자 데이터 폴더의 `auto_update.log`에 오류 기록.
- GitHub API 접근이 차단되거나 오프라인이면 검사 실패로 앱 시작 자체가 막히지 않도록 기존 버전을 계속 실행.
- 현재 사용자가 정식 출시를 승인하지 않았으므로 공개 베타 버전만 자동 설치. Stable 자동 설치는 비활성화.
- `v0.8.5-beta.2` 및 그 이전 버전은 업데이터 미탑재: `v0.8.6-beta.1`의 최초 1회 수동 설치 필요.
- 임의 위치의 사용자 수정 `aliases.json` 및 `artwork.xml`을 자동 덮어쓰지 않음. 향후 해당 파일이 배포 필수로 변경되는 경우 별도 호환성 정책 필요.

## PortMaster 지원 범위 및 확인 필요 사항 (v0.8.7-beta.1)

- `roms/ports` 최상위 `.sh` 게임을 조회, `port.json` + `gameinfo.xml`로 명확히 매칭되는 포트의 정보만 `ports/gamelist.xml`에 보완함.
- 설치 방식에 따라 `port.json`/`gameinfo.xml`가 장치에 존재하지 않거나 예상한 폴더 밖에 있을 수 있음. 이 경우 임의의 다른 게임 정보를 덮어쓰지 않고 검색 실패로 처리.
- 영상·매뉴얼·추가 외부 미디어의 자동 획득은 이번 PortMaster 전용 흐름에 포함되지 않음. 이미 설치된 cover/screenshot 경로를 사용함.
- PortMaster 런처 외 설치/관리 스크립트는 게임 목록에서 제외. **기기 포트 데이터 폴더/세이브 파일을 삭제하지 않음.**
- 정보 누락 항목만 채우므로 기존에 잘못 설정된 메타데이터의 강제 교체는 미지원.
- 실제 RG35XX Plus/Windows USB ADB 조합에서 PortMaster 포맷 편차 검증은 아직 필요.

## Atomiswave 7z 인식 누락 (v0.8.7-beta.2)
- 이전 버전에서는 `.7z` 확장자가 허용돼 있어도 `atomiswave` 폴더 자체가 시스템 목록에 없어 모든 Atomiswave ROM이 누락됨.
- `core.SYSTEM_IDS` 및 `legacy_bridge.PLATFORMS`에 Atomiswave 추가. ScreenScraper 시스템 ID 53, Skyscraper 플랫폼 이름 `atomiswave`.
- Atomiswave `.7z` 및 전용 `.lst`/`.dat`와 한글 하위 폴더의 탐색을 회귀 테스트에 추가.
- 실제 사용자 Windows/RG35XX Plus에서의 목록 조회·스크래핑은 아직 별도 확인 필요. 게임 실행 가능 여부나 BIOS/에뮬레이터 문제는 이 스크래퍼의 범위가 아님.

## 조사 필요 시 보고서
사용자가 올리는 `work/last_report.json`을 분석한다. 보고서에 민감한 경로나 계정정보가 포함될 수 있으므로 공개 저장소에 원문 업로드 금지. 재현 가능한 최소 예제만 사용.

## 잠재 안전 문제
- **중요:** 사용자 요청에 따라 v0.8.5-beta.2부터 자동 XML 백업이 없음. USB 연결 끊김/장치 오류에 대한 복구 수단이 줄어들며, 사용자가 원할 때 별도 외부 백업을 보관해야 함.
- 구버전 PC 설치 폴더가 최신 프로그램과 다른 상위 폴더에 있으면, 해당 폴더의 백업은 안전을 위해 자동 검색·삭제하지 않음.
- ZIP 세트 이름과 게임 실행 참조 파일이 복잡하면 실제 이름 변경 제한.
- 사용자 Windows 비밀번호·ScreenScraper 자격 증명 GitHub 공개 금지.
- 자동 테스트 성공을 실제 기기 성공으로 오인하지 말 것.
