# 알려진 문제 및 검증 상태

## 아직 검증되지 않은 사항
- **v0.8.5 ROM 삭제 후 자료 정리:** 실기기 테스트 전. `gamelist.xml`에 명시적으로 연결된 안전한 미디어 경로만 삭제 후보로 취급; 파일명만 유사한 미연결 자원은 삭제하지 않음. 다른 게임과 공유한 경로는 보호. 조회 시 사용자가 정리 승인해야 실제 삭제됨. **v0.8.5-beta.2부터 XML 백업도 생성하지 않음.** 미디어 정리 전 사용자 확인 필수.
- **모든 게임이 삭제된 ROM 시스템:** v0.8.5에서 빈 목록 처리 코드를 보완했으나, 실제 기기에서 해당 시나리오의 동작은 아직 검증 전.
- **v0.8.4의 한글 하위 폴더 수정이 실기기에서 성공했는지:** 사용자 재실행 결과 미수신.
- **타이틀 화면(ssTitle):** KNULLI는 지원하지만 Windows Skyscraper 3.6.12에서 별도 타이틀샷 다운로드/적용 경로 미검증.
- **대형 ROM 속도:** 구형 Skyscraper는 임시 복사가 필요할 수 있어 느릴 수 있음.
- **전 게임기/파일 형식 호환:** 특히 `.cue`/`.bin`, `.m3u`, 다중 디스크, 아케이드 세트는 더 검증해야 함.
- **실제 Windows 자동 설치:** ADB와 Skyscraper 설치 경로·DLL·압축 해제는 기기별로 환경 차이가 있음.
- **GUI 미디어 미리보기:** JPG/WEBP에 Pillow가 필요할 수 있음.

## 이번에 수정한 문제
- v0.8.5-beta.1 실기기: `삭제된 게임 검사 실패: ADB shell failed: error: shell command too long`. 한글 경로 인코딩이 긴데 12개씩 묶고 한 경로를 두 번 인코딩해 ADB 셸 명령 크기 초과. v0.8.5-beta.2에서 명령 크기 제한·재분할·실패 시 중단하도록 수정. CI 테스트 통과, **실기기 재시험은 아직**.

## 해결 기록

- v0.7: Platform-Tools ZIP 최상위 폴더 판정 오류 수정.

- v0.8.2~0.8.3: 선택 행 음영과 영문 `<name>`을 한글 표시명으로 유지하는 문제 수정.
- v0.8.4: 한글 하위 폴더 출력의 `????`, `remote file size unavailable` 경로 인코딩 수정(가상 테스트 확인).

## 조사 필요 시 보고서
사용자가 올리는 `work/last_report.json`을 분석한다. 보고서에 민감한 경로나 계정정보가 포함될 수 있으므로 공개 저장소에 원문 업로드 금지. 재현 가능한 최소 예제만 사용.

## 잠재 안전 문제
- **중요:** 사용자 요청에 따라 v0.8.5-beta.2부터 자동 XML 백업이 없음. USB 연결 끊김/장치 오류에 대한 복구 수단이 줄어들며, 사용자가 원할 때 별도 외부 백업을 보관해야 함.
- 구버전 PC 설치 폴더가 최신 프로그램과 다른 상위 폴더에 있으면, 해당 폴더의 백업은 안전을 위해 자동 검색·삭제하지 않음.
- ZIP 세트 이름과 게임 실행 참조 파일이 복잡하면 실제 이름 변경 제한.
- 사용자 Windows 비밀번호·ScreenScraper 자격 증명 GitHub 공개 금지.
- 자동 테스트 성공을 실제 기기 성공으로 오인하지 말 것.
